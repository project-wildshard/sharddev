# CI21 frozen guests

The engine cannot compile shard SDK scripts in its own test suite. The one-shot
exporter emits a fixed ABI2 return-projection guest plus its source receipt for
the engine-owned fixture bank.

It also emits three raw-ABI legacy guests and the two-stream group-RNG guest,
so the engine suite can keep those runtime laws without importing the SDK.

The bank includes the group-member native-effects guest with its declared ABI2
layout, preserving the source beside the emitted bytes.
