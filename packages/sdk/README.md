# @wildshard/sdk

The Wildshard author SDK and the `wildshard` CLI: build a shard source into a shard file, check it, play it locally and
upload it. Start with [GUIDE.md](GUIDE.md).

This package lives in [sharddev](https://github.com/project-wildshard/sharddev) under `packages/sdk`, beside
`@wildshard/kit` (shared creature content) and `@wildshard/upload` (upload, account and delete). All three release at
one version.
