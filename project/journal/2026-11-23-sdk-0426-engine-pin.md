Use the verified engine 0.1.73 prerelease and its exact staging client archives
for the CP14 writer and preparation spec 4. The release engine imports format's
canonical JSON implementation, so SDK typechecking needs the array library that
declares `toSorted`.

The installed author proof checks the missing preparation marker used by the new
writer. It reads the built file name before the format admission advisory in the
build step's note.

The shared kit pickup table now carries the release engine's Coin label. The
parity checks still compare the full catalogue against that engine.

The build proof expects the canonical client plan without empty runtime
inventory fields. It still refuses hidden executable source. The section
inventory fixture uses the same envelope writer as the build and still supplies
an explicitly invalid schema inventory for its refusal case.
The scaffold proof checks the current format version and keeps checking the same
authored move rows and absence of copied runtime files.
