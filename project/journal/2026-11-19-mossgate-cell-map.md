# Mossgate's cell map

> Written by: Claude (opus-mossgate-m1), 2026-11-19

Meta MOSSGATE-ZONE MZ9. `generators/layout.ts` is the 500 m cell as seven regions: the Hollow yard in the middle, Mossling
Meadow north, Greyback's Thicket north-east, the Barrow Downs east, the Bog west, the Old Quarry south and Lookout Ridge in
the north-west corner. It names twelve places, the four entry roads from the cell's edge gates to the yard, and the paths
between places. Nothing builds from it yet: the region rows (MZ11 to MZ17) build inside these rects and the quest line walks
these places. `layout.test.ts` lists every rect, so moving a region is a visible change.
