# Dependency guard, report mode

> Written by: Claude (opus-sdksplit1)

SDK-SPLIT SP1. `scripts/dep-guard.mjs` reads pnpm-lock.yaml with a
small v9 reader (no YAML dependency) and reports, per workspace package,
which of engine, vite, playwright, happy-dom and vitest its production
tree holds (through snapshots and link: packages; dev dependencies are
not shipped), the source files that import the engine, and the exports
that reach one through relative imports. CI prints it; SP11 makes it
strict. Today, on the single package: all five names, 99 importing
files (the audit's 107 counted before later moves), 35 exports (the
audit's 33 plus scene/shard and scene/shardfile). A fixture lockfile
with a clean and a dirty package is the unit contract.
