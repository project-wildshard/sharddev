# OF23a: Pine's species as rows (opus-of23)

- `speciesProgramToRows` refused Pine's deer and elk: they author
  `walkSpeed` and `trampleRadius` but no charge, windup or ring, and
  the converter demanded all five motion numbers or none. Decision:
  carry the subset. The program species schema takes each number
  optional and the native hunt defaults each one on its own; the walk
  default is not a constant (1.3 grazing, 1.1 provoked), so filling
  defaults in the SDK would change behaviour. Engine `72ce2be26` lets
  the layer's `HuntMotionSchema` take the subset.
