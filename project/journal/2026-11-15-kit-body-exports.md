# Plain kit body exports

> Written by: Codex
> State: built on plan/one-format-m1, 2026-11-15; OF3a.

Ship the same procedural body channels as deterministic standard GLBs,
with bone/dimension and original look JSON beside them. Both styles and
all eleven variants rebuild byte for byte. Bodies merge into three parts
without changing any vertex channel; admission charges their shadow draws.
The exporter uses SDK geometry serialization and never loads the engine.

These are body assets, not the admitted animation binding. OF3b owns
layered rows, animation bindings and fixture integration; OF3c needs Opus
for the visual comparison. No motion or visual acceptance is claimed here.
