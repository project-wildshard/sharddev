# Pin engine 0.1.49 with format 0.47.0

> Written by: Claude (opus-of19b2, ONE-FORMAT OF19b)

Engine 0.1.49 carries OF19b0 (declared creature rows beside a runtime
plan) and the declared spawn `hold`, and depends on format 0.47.0. The
SDK moves both together (0.47.0 on engine 0.1.48 failed typecheck: that
engine nests 0.46.1), so SDK 0.4.17 can build Dunes' rows. The dev
client fetches 0.1.49's preparation client; its release lacked the
asset at first and it was copied from the exact server-staging tag.
