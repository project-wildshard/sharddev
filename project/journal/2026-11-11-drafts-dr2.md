# Drafts site builds in sharddev (meta DRAFTS-PLAN DR2)

- `drafts/` came over from singleplayer on 11-07 but nothing built or
  tested it. Added `pnpm drafts:build` (to `tmp/dist-drafts`,
  `version.json` now carries `sha`), `pnpm drafts:dev` (localhost:5190)
  and `pnpm drafts:test` (typecheck, vitest, `atlas.ts --check`).
  `drafts/test/**` is in the vitest include, so `pnpm test` runs it.
- The tsconfigs referenced singleplayer's `tsconfig.game.json`, which
  broke every drafts test transform here. Now plain, noEmit.
- Originals (art rounds, design docs) stay in singleplayer (D5). The
  tools take `--sources <dir>`; without it `tools/sources.ts` rebuilds
  from the committed `atlas.json` + `images.json`, so 13 tests that
  were skipped without `art/` now run in CI, and `--check` works on a
  machine with no singleplayer checkout.
- `atlas.ts` no longer writes `src/game/draftTitles.ts` (an engine file
  now); `--engine <checkout>` writes engine's copy (DR5 uses it).
- Dev serves `/media/*` from the DR1 Blob export; the built site still
  points at Blob until DR3 moves the pictures to R2.
- Webp scratch and the deploy export moved from `/tmp` to repo `tmp/`.
