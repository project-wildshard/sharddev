with private node counts and getter-call instrumentation. New explicit
CI proofs use installed public engine and format modules. SDK owns six
language/consumer cases; Driftwood and Pine each evaluate their actual
pose source for 300 frames against independent lanes, including repeated
input frames. Every published value must exist, be finite and compare
with Object.is; an empty source cannot pass.

isolation, both clocks, mutable source output and unused-invalid-math

are deliberately outside these value laws. No original SDK file or

complete-body elapsed assertion. No source, pins or pose data changed.

requires the frozen normal publication capture and exact hosted CI.
