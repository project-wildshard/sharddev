# Engine 0.1.48 pin

> Written by: Claude (opus-of-npm48), 2026-11-19

sharddev moves from engine 0.1.47 to 0.1.48 (npm latest, prod serial 35) and from format 0.45.0 to 0.46.1, the
format the engine itself depends on, so the author tools and the engine read one copy of the rows. 0.1.48 carries
`821a3c643` (the tail on the server and the page poser for a horizontal stance), which ONE-FORMAT CC58c's T-Rex
fixture needs, and OF42b's tape kit swing for OF42c.

0.1.48 pins `@wildshard/wire` at exactly 1.5.0, so the root override that held the engine on wire 1.2.0 goes, and
with it the 0.1.47-only packed headless worker (`scripts/pack-headless.mjs`, the `prepack`, the `.gitignore` line and
the wire resolver in `scripts/wildshard.mjs`), which was keyed to `0.1.47` with a `^1.2.0` wire range and had become
inert. The dev package's direct wire dependency only fed that resolver.
