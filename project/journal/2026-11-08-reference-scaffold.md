the real door command failed with Unknown authored interaction. Default
new now copies the package's complete Template 1 source, with a new
identity and asset namespace. The original generators, geometry and art
are copied unchanged. Empty remains an explicit --empty choice; the
existing library newProject helper keeps its empty-project behaviour.

world outside the checkout, refuses distant use, walks to and opens the
door, crosses the collider, and resumes the actual saved state. Full
procedural generation exceeds ten seconds locally, so the new reference
proof runs only in Ring 2. The quick empty-author cases stay in CI and
continue to use the shipped bin. Neither new test joins a hook.

including attacks and a physical route behind the hut earned the door
and hut flags but no kill. The pinned declared worker uses HOST_PROBE
(zero damage) without the native item command owner. Its public attack
command cannot prove this fight. No event, damage, save field or special
test port was injected. This lane changes no engine source; the engine
