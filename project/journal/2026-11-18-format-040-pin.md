# Format 0.40.0 pin (meta ONE-FORMAT, opus-sdkpin)

- sharddev moves `@wildshard/shard-format` 0.37.1 -> 0.40.0 everywhere (root
  override, sdk, dev, build, upload, kit). It unblocks CC24b (serpent trail
  rows) and readies OF27b2 and OF11b for 0.41.0.
- Engine 0.1.44 (the newest on npm) still indexes `CREATURE_SKELETONS` by a
  serpent, which 0.40.0 types out (`FixedSkeleton`), and misses the brain
  binding in `decisions.ts`. `patches/@wildshard__engine@0.1.44.patch`
  backports engine main's `bodyContract` and the `'brain' in binding` arm so
  the one format copy typechecks. Drop it when the sdk pins an engine
  release past 0.1.44 (engine main has both).
- SDK: the new script ABI commands (`lockable`, `heal`, `pull`, `root`,
  `ability`, `actorChannel`) and the `part.broken` event get guest bindings
  in the host's [target, a, b] slots; skeleton lookups go through
  `creatureContract` or refuse a serpent where a kit chain map is fixed.
- J424/J426 in 0.40.0: a stale runtime reading refuses only an armed zone,
  so `client-runtime-declaration.test.ts` proves both sides.
- Same day, 0.41.0 (OF27b1 skins, d493da7a legless flyers and camelCase
  spawns): no source change; OF11a's pin-wait test now admits all four
  Dunes species, spawned. The engine 0.1.44 patch still applies.
- CC24b: `world.creature` takes `trail` (a serpent's rig is the `body`
  bone every skin needs with head, seg1..., tail under it) and `clipMap`
  (parsed with the format's schema, every clip a rig clip).
