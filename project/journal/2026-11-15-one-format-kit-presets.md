# A JSON catalogue with helpers beside it

> Written by: Codex
> State: CC2a built locally, 2026-11-15; M1 land and release pending.

packages/kit holds four copied tuning documents, nine temperament profiles,
five ability templates and two body defaults. Helpers read the JSON and
validate the same format fields. No runtime owner or body builder is added.

The direct source proof compared every field of the copied boar, bear and
deer tuning with their current engine definitions and pursuit with the
Template's existing brain row. Their serialized numeric values match exactly.
The ability numeric values come from existing Template and pinned Brasscap
strikes; only their identities and tags become kit names. Source pin for
Brasscap: e99b0fb45c96faf4241e1dc72bf812ac17a175757322e87233f7ef2d0518d2d2.

Four focused cases prove catalogue/helper JSON identity, body options,
independent overrides and invalid-number refusal. The kit project passes
its own typecheck and strict lint. Package integration, copied built rows,
dependency lock and publication belong to CC2b.

The format subpaths are unpublished. Only this worktree's isolated kit
node_modules links the M1 format branch for proofs (recorded in the lane
receipt); the root SDK pin is unchanged. Replace the proof link with the
published dependency before the single M1 land. No peer checkout was changed.

subpaths. A packed 0.1.0 archive contains the plain JSON and helper sources,
