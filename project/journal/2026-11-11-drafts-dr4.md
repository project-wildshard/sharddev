# Drafts site on a Cloudflare Worker (meta DRAFTS-PLAN DR4)

- New Worker `wildshard-drafts` (`drafts/wrangler.jsonc`, `drafts/worker.ts`)
  at https://drafts.wildshard.io and `wildshard-drafts.wildshard.workers.dev`.
  Static assets come from `tmp/dist-drafts`; `run_worker_first` so the Worker
  sets the cache headers and `x-robots-tag: noindex` that `public/vercel.json`
  used to set (that file is gone).
- `/media/<slug>/<hash>-<full|thumb>.webp` reads R2 `wildshard-records` key
  `drafts/<slug>/…`. Anything else under `/media/` (www's `site/media/`, `..`,
  other extensions) is a 404 that never calls R2; `drafts/test/worker.test.ts`.
- `pnpm drafts:deploy` is the rewritten `drafts/tools/deploy.sh`: a clean HEAD
  export in `tmp/drafts-deploy`, vite build, `wrangler deploy`, then polls
  `version.json` for HEAD's sha.
- The custom domain overrides the zone's wildcard `*.wildshard.io` CNAME to
  Vercel (`cname.vercel-dns-016.com`) for `drafts` only; no record of that
  name existed before.
- `atlas.ts` and `artifact.ts` link to drafts.wildshard.io now. Vercel itself
  is untouched until DR6.
