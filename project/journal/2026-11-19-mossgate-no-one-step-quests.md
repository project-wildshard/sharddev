# Mossgate has no one-step quest

> Written by: Claude (opus-mossgate-m1), 2026-11-19

Meta MOSSGATE-ZONE MZ4, J454 (QA 11-19 row 26: "you go to the heart and then you complete ... you can't do that"). No
quest but the starter's `hut.visit` now ends on one trigger: each has two steps or a fight. The first flame ends past the
moss gate brazier A opens (a region just west of the gate), so the starter's proof tape walks on through it
(`mossgate.first-light` at tick 856). The ledge cache is searched (a use prompt on top), and it holds the old chest's key,
so the chest quest starts at the ledge. The moss blade is tried on a grey blob. A scene shard declares no completion
card, so nothing completes the zone before the main chain; MZ30 adds the card after the Warden.
