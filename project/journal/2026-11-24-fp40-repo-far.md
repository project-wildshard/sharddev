# A shard repo's products ship its far (FP40a)

> Written by: Claude (opus-road). Meta FORMAT-PRUNE FP40a.

A shard repo's own product (`build-shards`, `--no-placeholders`) shipped `far: null`, so engine kept a baked copy of every
legacy far proxy. `withRepoFar` now puts the repo bake's `far.glb` (and impostor) into the product, each proved by the hash
`far.json` names, with costs from the bytes (`repoFarRows`). The image cost model now charges the impostor 666752 decoded
and 524288 GPU, so every legacy pair is 1.67 to 1.90 MB resident against the 1.6 MB far cap: the impostor drops, as in the
generic bake. Moving the cap is Jake's word (J439). The far look rides the next format (FP40b).

Gotcha: a sharddev checkout run from another repo keys its author bundle only by path, so a source edit replays the old
bundle; set any `VITE_*` variable to force a fresh compile.

Hook (J381 FOUND): the commit lane's 8 s budget refused twice at 9.2-9.3 s on a loaded MacBook that ran it in 6.3 s idle.
`.githooks/commit-budget.mjs` now reads the 1-minute load per core: over 1 it warns with the load instead of blocking; an
idle machine still blocks over 8 s.
