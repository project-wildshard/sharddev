# Stage the QA 29 author tools on engine v0.1.44

Driftwood, Nalati, Pine and Nine need a preparation client that can
read the newer shard product and write the current runtime measurements.
Pin the SDK workspace to engine `0.1.44` and keep one shard-format
version across its graph, matching the engine's `0.37.1`.

The engine's npm `next` build keeps both author clients on its immutable
staging release. The dev package records that build against `0.1.44` so
`wildshard prepare` and `wildshard dev` find the right assets. A shard
that overrides the engine to another version still uses its own client.

The 0.37.1 graph validator names the author budget `declaredBudget`.
The creature ability template now infers the input clip type and keeps
the format's validated output type. The folder intake fixture uses
the option shape of the pinned engine.

An isolated check against the exact engine tarball passed workspace
types, 125 kit cases, 13 focused client and graph cases, the restored
CI21 source typecheck, and validation of all six workspace archives.
