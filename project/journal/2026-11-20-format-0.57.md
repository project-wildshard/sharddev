# Format 0.57.0: lap races

> Written by: Claude (opus-mirrorsalt-m10), 2026-11-20

The SDK, dev, build and upload packages pin format 0.57.0, which adds a race's `laps`, ordered `checkpoints`
and `ride` (meta MIRROR-SALT-ZONE MSZ31), so a shard can declare a lap race through its quest rows (Mirror
Salt's Rim Run, MSZ32).
