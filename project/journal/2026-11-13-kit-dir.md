# The kit moves out of src/ (K11, J329)

repo-kit v3 keeps its own tooling in `kit/`: the tsconfig, the oxlint
and oxfmt configs, and the asks, md-wrap and herdr scripts. sharddev's
code stays in `src/`, including `src/cli` and `src/test`, which are
the product's own.

- `kit-dir-move` moved the stamped files, then `kit.mjs apply` and
  `agent-sync` repointed the hooks and skills to `kit/scripts`.
- `src/tsconfig.json` extends `../kit/tsconfig.json` and lists the same
  folders as before, so `src/web/tsconfig.json` (`extends
  ../tsconfig.json`) still finds a base one level up.
- `src/.oxlintrc.json` extends the kit config with `src/`'s own
  ignores, because oxlint does not inherit `ignorePatterns`. `lint:kit`
  runs `node kit/scripts/lint.mjs`: kit's config on everything but
  `src/`, then `src/`'s on `src/`. `scripts/lint-dispatch.mjs` still
  routes author paths to `lint:author`.
- `.prettierignore` keeps its three author folders and adds the `src/`
  paths kit's oxfmt config used to skip (oxfmt refuses `..`). The
  first pass overwrote the file; the author lines were put back.

`pnpm check`, `test:hooks` (185) and `test:agent-hooks` (43) pass. A
probe file under `src/server` got the kit's rules (eqeqeq,
id-length), so the src run lints with the full config.
