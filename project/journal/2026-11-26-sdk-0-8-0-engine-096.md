# SDK 0.8.0 runs on engine 0.1.96

Meta QA 11-25 row 139 (opus-sdk139). sdk and dev repin `@wildshard/engine` from the prerelease `0.1.93-next.b2c9e9f3`
to `0.1.96`, engine's npm `latest`, so the next `latest` SDK passes the publish guard from `e45693f4`. v0.1.96's
GitHub release carries `devserver-client.tar.gz`, so `wildshard dev` fetches its client by the plain version and dev's
staging-client map needs no new entry.

Engine 0.1.96 deleted `legacySlot` from its melee profile (FORMAT-PRUNE FP22e), and the type test
`sdk-engine-types.test.ts` refused kit's profile against it. Kit's `MeleeProfile` drops the field and its `Slot` type
parameter (opus-prune2's kit hunk from `plan/fp20`; the rest of that branch waits on its own format release). An
author field gone is a break (D29), so this is 0.8.0, with `codemods/0.8.0.mjs` and GUIDE `migrate-0-8-0`: it drops
`legacySlot: '<name>',` lines from code that imports `@wildshard` and rewrites a flat three-argument `MeleeProfile`,
and names every other `legacySlot` line by file and line. No shard repo's code sets it today; shard-nine-dragon's
`test/fixtures/nine-item-equipment.json` names it in data, which shows up as a manual line.

Engine 0.1.96 runs on shard-format 0.80.0 (its folder admission calls `readsFormat`), and the workspace's override
pinned 0.79.3, so `return-projection-inventory.test.ts` failed on the engine's own boot. Every package moves to format
0.80.0, which deletes the species-program section, so opus-prune2's `98fd10f8` comes along: the SDK's own retired-section
guard and the tests that fed it that section go (the format refuses an unknown section itself). A dropped refusal
breaks no shard repo, so it needs no migration of its own.

Main's ci was red before this, in the CI21 source step: a4781ad9 changed a comment in the frozen witness
`src/game/client/shard/manifest.ts` without its provenance hash. The provenance records the new blob, and
`test/ci21-witness-hashes.test.ts` checks every witness hash in the sdk's own suite, so the pre-push catches the next one.
