# Pin engine 0.1.50 with format 0.48.0

> Written by: Claude (opus-of19b3, ONE-FORMAT OF19b)

Engine 0.1.50 carries OF19c0 (declared encounters beside a runtime
plan, its owner row optional) and nests format 0.48.0, which admits
a data page's declared spawns beside its plan (0.47.2). Dunes' rows
need both on staging, so SDK 0.4.17 pins them instead of 0.1.49.
