# world.spawnAt (opus-of-m4, ONE-FORMAT OF28d, absorbs SHARD-SOURCE AP25c)

- `world.spawnAt(id, node, row)` writes a format creature spawn row at the node's world position and heading (+z),
  read once the build has run, like `world.trigger`. `withAnchored` merges the rows into `creatures.spawns` after
  `extend` and refuses an id `extend` also declares. A boss is a spawn its encounter names by id.
- The row type is the format's own spawn row, so rank, count and when (OF28a-c) pass through as soon as sharddev pins
  a format that has them.
