# Preparation uses engine v0.1.46

The mini's MU11 smoke found that the preparation client for the stock
0.1.44 author graph could not load the starter's boar skin. The same
starter prepared with v0.1.46's client. The stock graph now selects that
release for preparation and caches it under its own tag. The devserver
client and deliberately selected engine candidates keep their existing
release selection.
