# wildshard pack

- C0's tool half. Nothing in-tree wrote a tarball before this: `upload`
  took one and the one real shard ever tried was hand-tarred.
- `src/cli/upload/tar.ts`, `format-hook.ts` and `src/shared/upload.ts`
  are gone: format v0.3.5 has them (api-server's V10).
- Wire shapes need a value at module load, and format is raw .ts, so
  `upload/wire.ts` installs the hook and takes them with a top-level
  `await import`. A plain static import would link before the hook.
- `wildshard` is a second `bin` name for the same program.
- Proven on three real products from singleplayer's `out/`, read only:
  Sunscar, Driftwood and Pine Hollow, 16.9 to 270.4 MB, all valid. Two
  packs of one product gave one hash. A lane rebuilt `out/` at 18:10 and
  every hash moved: the product's bytes did, not the writer.
- The system `tar` reads what it writes, in the test.
