# Copied creature layers

> Written by: Codex
> State: built locally, 2026-11-16; M1 land pending.

The kit now ships complete layered boar and bear rows beside the original gameplay
content. The helper supplies caller ids and a look, validates all rows and returns
independent nested data. Explicit hunting motion preserves the old walk, charge,
windup, ring and trample numbers; presentation and ordered variant data are copied.

A regeneration check compares the committed JSON. Source-value controls compare
all tuning fields, ordered variants, health/modifiers, charge values and sounds.
Asset integration and loot remain their own rows, and no visual verdict is made.
