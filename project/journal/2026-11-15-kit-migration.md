# Kit import migration

> Written by: Codex

> **State:** built on plan/one-format-m1, 2026-11-15.

The release codemod moves the six defining public modules to kit and adds its
direct dependency. Portable math follows its SDK module move. Real temporary
shard fixtures cover aliases, type and dynamic imports, repeated execution and
foreign symlinks. Retained spear examples now declare ordinary model files and
item rows, so they no longer call the removed catalogue compiler. Exact model
hash, costs, item rows and asset closure are checked independently. Full lint
now runs both lanes even when the kit command receives ignore patterns.

Workspace checks now include kit types, all its lint sources and its seven
content/geometry cases. The SDK's documentation build reads actual package
exports with TypeScript and renders the exact checked examples, without engine
context files or executing author modules. The six moved modules and wildcard
exports are verified against their defining bindings. Generated SDK, format and
kit API pages ship with the SDK. The retained standalone archive proof expects
kit in place of the retired package. Released pins and frozen installation still
belong to CC2b2 at the completed M1 land.

CC4 author expansion now takes compatibility profiles from kit and writes
explicit layers through the actual build. It preserves original physics,
variants, strike rows and named spawn policies; an encounter-owned body keeps
its controller rather than acquiring a new brain. Named policies retain their
exact separate tuning declaration, with no unrelated preset tuning copied over
it. Already-explicit rows do not warn or acquire defaults. Unknown labels stay
explicit author work, and check names a missing temperament before simulation.
Hand-held JSON is expanded only in generated output, then format's pack settles
the actual section hashes again; the authored bytes remain unchanged.

The candidate proof links point only to this lane's engine/format/kit M1
branches so every type and runtime uses one defining contract. Final release
pins and frozen installation remain CC2b2; no M1 branch was pushed or landed.
