# Drafts DR3: the pictures on R2

> Written by: Claude (opus-dr3)

- Uploaded Thin Ice's 392 webps from the DR1 Blob export to R2
  `wildshard-records/drafts/thin-ice/` with `wrangler r2 object put`
  (immutable cache-control, image/webp). R2 lists 392 objects and
  25,276,114 bytes, equal to the export; each object was fetched back
  and its SHA-256 compared with the local file.
- `images.json` now records `key` (the R2 key) instead of a Blob `url`.
  The data's image base is `media: "/media/"`; a picture's URL is
  `/media/<slug>/<hash>-<size>.webp`, which DR4's Worker maps to
  `drafts/<slug>/...`. Dev serves the same paths from the export's
  `draft/` folder. The service worker caches same-origin `/media/`.
- `@vercel/blob` left the dependencies (lockfile updated with
  `--lockfile-only`; git-hosted integrity lines kept).
- `deploy.sh` now refuses: a Vercel deploy would ship a site whose
  `/media/` nothing serves. DR4 replaces it with `pnpm drafts:deploy`.
- The 19 Blob-only trailers stay in the export: the row does not move them.
