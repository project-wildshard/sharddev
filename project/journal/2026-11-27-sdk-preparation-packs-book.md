# The preparation preview describes its empty packs

Driftwood's signed 0.1.99 preparation client asked for the build's
packs book before control. Inline preparation serves the candidate
files directly, so give that exact build an empty book where the
client archive lacks one. Leave any shipped book in place. The
recorder only reads response bodies that can contain a manifest.

The stock client entered Driftwood in headless phone WebKit and
recorded 97 programs with the patch.
